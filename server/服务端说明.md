# 服务端说明

服务端是一个无外部数据库依赖的 FastAPI 进程，负责 Markdown 图谱索引、内存 DAG 执行，以及知识看板与任务工作流。持久数据只落在两个地方：Vault 下的图谱快照文件，和本地 SQLite 投影（知识健康与任务）。

## 运行模型

- `DirectoryScanner` 扫描 Vault Wiki 与仓库 Markdown，解析 frontmatter、标题、WikiLink 和 Markdown 链接。
- 图谱快照写入 Vault 下的 `.inkdesk/graph/snapshot.json`，可从文件重建。
- Watchdog 监听 Markdown 变化，`/api/graph/stream` 通过 SSE 推送更新。
- `EngineRuntime` 使用内存 Kahn/BFS 调度器执行任务，结果通过 SSE 返回。
- `KnowledgeService` 是只读视图，叠在图谱索引之上，产出主题卡片、简报与来源追溯。
- `KnowledgeHealthRuntime` 与 `TaskRuntime` 使用标准库 `sqlite3`（WAL 模式）做本地投影，默认落在 `server/.data/inkdesk.sqlite`，可通过 `INKDESK_DATABASE_PATH` 覆盖；Vault Markdown 仍是长期真相，该投影可随时从文件重建。
- 服务不初始化 PostgreSQL，不维护检索 chunk，也不持久化任务队列。

## 本地运行

```powershell
python -m pip install -e ".[dev]"
$env:INKDESK_VAULT_ROOT='C:\path\to\vault'
$env:INKDESK_REPO_ROOT='C:\path\to\repository'
python -m uvicorn inkdesk_server.main:app --host 127.0.0.1 --port 8080
```

模型调用是可选能力。没有 API key 或 `INKDESK_AGENT_RUNTIME=deterministic` 时，DAG 使用本地确定性执行器。

## 环境变量

- `INKDESK_VAULT_ROOT`：Vault 根目录。
- `INKDESK_REPO_ROOT`：要索引的仓库根目录。
- `INKDESK_ENABLE_FILE_WATCHER`：是否监听文件变化，默认 `true`。
- `INKDESK_GRAPH_SSE_HEARTBEAT_SECONDS`：SSE 心跳秒数，默认 `15`。
- `INKDESK_DATABASE_PATH`：本地 SQLite 投影路径，默认 `server/.data/inkdesk.sqlite`。
- `INKDESK_AGENT_RUNTIME` 与 `INKDESK_AGENT_*`：可选模型执行器配置。

## 接口

图谱与执行：

- `GET /health`
- `GET /api/graph`
- `GET /api/graph/document`
- `GET /api/graph/stream`
- `GET /api/engine/health`
- `POST /api/engine/stream`

知识看板（`/api/knowledge/*`）：

- `GET /api/knowledge/topics`、`GET /api/knowledge/search?q=...`
- `GET /api/knowledge/topics/{topic_id}/briefing|sources|document|claims`
- `GET /api/knowledge/documents/{document_id}`
- `GET /api/knowledge/signals`、`GET /api/knowledge/signals/{signal_id}`、`POST /api/knowledge/signals/{signal_id}/actions`
- `GET /api/knowledge/claims/{claim_id}`、`GET /api/knowledge/claims/{claim_id}/evidence`
- `GET /api/knowledge/health/summary`
- `GET /api/knowledge/reviews`、`POST /api/knowledge/reviews`、`POST /api/knowledge/reviews/{review_id}/decision`
- `GET /api/knowledge/stream`（SSE，事件 `knowledge.updated`）

任务工作流（`/api/tasks`）：

- `GET /api/tasks`、`POST /api/tasks`
- `GET /api/tasks/stream`（SSE，事件 `tasks.updated`）
- `GET /api/tasks/{task_id}`、`POST /api/tasks/{task_id}/context`、`POST /api/tasks/{task_id}/transition`

Harness 与执行器：

- `POST /api/runs`、`GET /api/runs/{run_id}`、`GET /api/runs/{run_id}/report|permissions|events`
- `POST /api/runs/{run_id}/cancel`、`POST /api/runs/{run_id}/permissions/{permission_id}/decision`
- `GET /api/executors/{executor_name}`、`POST /api/executors/{executor_name}/probe`
- `POST /api/skills/{skill_id}/stream`
