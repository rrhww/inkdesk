# scoring-formula

wiki 健康分的计算公式。run-wiki-health 输出健康报告时使用此公式。

## 基础分

满分 100 分。

## 扣分项

| 问题类型 | 严重度 | 扣分 | 上限 |
|---------|--------|------|------|
| 缺失 frontmatter `name` | ERROR | -5/个 | -30 |
| `[[wikilink]]` 断链 | ERROR | -3/个 | -20 |
| 缺少 `updated_at` | WARN | -1/个 | -10 |
| 孤页 | WARN | -2/个 | -15 |
| 短页（非 stub） | WARN | -2/个 | -15 |
| accepted 页面缺来源 | WARN | -3/个 | -15 |
| outdated 标记超过 180 天 | WARN | -2/个 | -10 |
| stale（>90 天未更新） | INFO | -0.5/个 | -5 |

## 健康分

```
health_score = max(0, 100 - SUM(扣分))
```

## 等级

| 分数 | 等级 |
|------|------|
| 90–100 | A — 健康 |
| 75–89 | B — 良好 |
| 60–74 | C — 需关注 |
| 40–59 | D — 较差 |
| 0–39 | E — 严重 |

## 趋势计算

对比上次健康检查记录：
- **改善**：健康分上升 ≥ 3 分，或 ERROR 数减少
- **恶化**：健康分下降 ≥ 5 分，或 ERROR 数增加
- **稳定**：变化在 ±3 分以内

## 权重说明

- ERROR 权重最高——断链和缺 frontmatter name 是信息丢失
- 时效性扣分软——stale 不一定意味着错误
- 不因页面数量多而惩罚——大型 wiki 可以有更多 INFO 项

## 不做

- 不与外部 wiki 做对比评分
- 不把健康分当作「内容质量分」（那是评测的职责）
