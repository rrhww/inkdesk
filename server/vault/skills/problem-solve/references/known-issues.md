# known-issues

problem-solve 诊断时可参照的已知问题和历史修复记录。此文件由 deposit-answer 沉淀的事实/规则类知识逐步积累。

## 使用说明

本文件是「已知问题库」——诊断时先对照此文件查看问题是否已有记录和解决方案。
当前为初始版本，内容在实战中由 deposit-answer 逐步填充。

## 使用方式

1. 诊断时：先搜索本文件，检查是否有匹配的已知问题
2. 修复后：如根因具有复用价值，建议通过 deposit-answer 沉淀到此处

## 不做

- 不预先填充未经实战验证的条目
- 不替代 wiki（wiki 记录结构化知识；本文件记录经验性的问题修复对）
