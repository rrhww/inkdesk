# 为什么 Today Vault Panel 应成为登录后的第一屏

如果首页先看到的只是旧笔记列表，系统会再次退化成存储工具。

Today Vault Panel 的作用，是先把 raw、ingest、wiki 与 Ask 组合成一块研究驾驶舱，让主人一进来就知道该读什么、审什么、追问什么。
