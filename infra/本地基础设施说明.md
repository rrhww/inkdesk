# 本地基础设施说明

当前运行链路只需要 FastAPI 和 Next.js。PostgreSQL、pgvector、MinIO 与数据库迁移已从默认容器拓扑移除。

## 启动完整本地栈

```powershell
Copy-Item infra/.env.example infra/.env
docker compose --env-file infra/.env -f infra/docker-compose.local-docker.yml up -d --build
```

默认端口：

- Web：`3000`
- FastAPI：`8080`

`local-server` 使用具名卷保存 Vault，并以只读方式挂载仓库供 Markdown 图谱扫描。`local-web` 通过内部服务名访问 API。

仅启动后端：

```powershell
docker compose --env-file infra/.env -f infra/docker-compose.yml up -d --build
```

停止服务并保留 Vault：

```powershell
docker compose --env-file infra/.env -f infra/docker-compose.local-docker.yml down
```
