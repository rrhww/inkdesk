Inkdesk 的 JWT token 过期后如何处理？
系统回答
根据 vault 中的 auth/api-auth.md 文档，JWT token 过期后客户端应使用 refresh token 请求新的 access token。refresh token 有效期为 7 天，过期后需要重新登录。
