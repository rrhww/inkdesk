# Teaching Method

## Sequence

1. Orient the learner with a short outcome and event map.
2. Rewind to a pivotal moment using only facts known at that moment.
3. Ask for the next action, expected result, and interpretation before exposing the expert path.
4. Reveal the observed decision trace with evidence labels.
5. Contrast the actual path with a more efficient path when useful.
6. Explain the smallest causal model that makes the evidence predictable.
7. Present a near-transfer challenge with changed surface details.
8. Ask the learner to write a future trigger, first check, belief-changing evidence, and verification step.

## Feedback

Diagnose the specific gap instead of grading the learner globally:

- Missing hypothesis: show which observation it explains.
- Weak test: explain why both hypotheses could produce the same result.
- Premature conclusion: identify the missing disconfirming evidence.
- Correct answer with weak rationale: ask for expected outcomes and interpretation.
- Strong answer: shorten explanation and increase transfer difficulty.

## Progressive Disclosure

Keep reference answers inside collapsed `<details>` elements. Phrase summaries neutrally so the collapsed label does not reveal the answer. Keep the learner's text area before the reference path in document and tab order.

## Fidelity Labels

- `evidence`: directly visible in the session.
- `reconstruction`: plausible interpretation of visible actions; use calibrated language.
- `recommendation`: a better method proposed after the fact.

Never merge the three labels or imply that a recommendation occurred in the original session.
