# Evaluation Cases

Evaluate the Skill against raw session artifacts, not a prewritten expected lesson.

## Cases

1. A deterministic bug with one clear root cause and a regression test.
2. An intermittent bug where three hypotheses are narrowed by logs and a minimal reproduction.
3. A bug solved after repetitive low-information trial and error.
4. An ambiguous feature request whose scope changes after clarification.
5. A design choice between two reasonable approaches with explicit constraints.
6. A completed feature where the Agent performed nearly all implementation work.
7. A formatting-only task with no substantial learning episode.
8. A partial transcript containing secrets or unavailable earlier context.

## Assertions

- Select a transferable episode or decline when none exists.
- Preserve the difference between evidence, reconstruction, and recommendation.
- Ask before revealing and keep reference content collapsed initially.
- Include informative failed attempts without producing a transcript timeline.
- Produce a transfer task that changes surface details.
- Keep initial mastery at `exposed`.
- Avoid source code, secrets, or full logs in persisted learner data.
- Generate an offline, responsive, keyboard-usable HTML document.
