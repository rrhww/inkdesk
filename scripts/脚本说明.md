# 脚本说明

这里用于放置仓库级开发辅助脚本和自动化脚本。

已落地的本地联调脚本主要在 `web/scripts/`：

- `fullstack-preflight.mjs`：检查真实后端、数据库和环境变量是否满足全链路 E2E 前置条件
- `run-fullstack-e2e.mjs`：在本地全栈环境上执行浏览器验收

`scripts/f01/` 用于结构迁移前的当前行为与恢复基线：

- `capture-baseline.ps1`：默认 Docker 栈的完整契约、测试、备份、隔离恢复和证据 manifest 采集入口；最近一次默认 Compose `-Mode all` 认证为 `PASS`（run `20260711T113950Z`）。
- `backup-local.ps1`、`restore-drill.ps1`：PostgreSQL + Vault 成对快照与隔离恢复编排，不会覆盖源数据库或活动 Vault。
- `export_openapi.py`、`export_postgres_schema.py`、`export_representative_records.py`：生成或比较脱敏行为契约。
- `verify_baseline.py`、`capture_summary.py`：校验证据哈希、已知问题纪律和完整 `all` 采集状态。

完整运行规则和数据边界见 `docs/delivery/baselines/f01/README.md`。真实运行产物只写到 `.local/f01-baseline/`。

`scripts/f02/` 用于 Python Alembic migration authority 的真实演练：

- `verify-migrations.ps1`：验证 F01 evidence 后创建 `inkdesk_f02_*` 临时库，执行 fresh upgrade、F01 strict adopt、数据指纹、只读 API、unsupported schema 和 lock 验证，并清理所有目标。
- `build-migration-report.py`：只在 F01 与全部 checks 均为 PASS 时生成脱敏 F02 manifest。

真实运行产物只写到 `.local/f02-migrations/`。
