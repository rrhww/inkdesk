# 智能模拟面试系统 PRD

## 产品目标

为校招候选人提供本地优先的模拟面试工作流。系统根据目标岗位生成结构化问题，记录回答，并给出可追溯的能力评估和改进建议。

## MVP 范围

- 用户输入目标岗位、技术栈和面试时长。
- 系统生成一轮包含技术基础、项目深挖和行为问题的面试。
- 每个问题保存回答、评分依据和改进建议。
- 运行过程必须可观察，失败必须返回稳定错误信息。
- 面试记录保存在本地，不上传未授权的个人信息。

## 验收标准

1. 可以从一份 Markdown PRD 启动技术方案生成。
2. 方案明确模块、接口、数据流、安全风险和测试范围。
3. 方案写入 Vault 后，知识图谱无需刷新页面即可出现新节点及其 PRD 依赖边。

## 非目标

- 本里程碑不生成业务源码。
- 本里程碑不接入招聘平台或实时音视频。
- 本里程碑不实现 MCP 服务。
