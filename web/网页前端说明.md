# 网页前端说明

Inkdesk Web 是一个只读的知识拓扑监控界面。

## 页面

- `/` 与 `/app`：重定向到 `/app/wiki`
- `/app/wiki`：知识节点、证据覆盖和治理风险总览
- `/app/wiki/[id]`：单个知识节点详情
- `/app/raw`：来源快照，只读
- `/app/health`：Vault 健康检查
- `/app/skills`：Skill Registry 只读视图

旧的 Ask、Ingest、Compile、Runs 工作台及侧栏导航已经物理删除。

## 数据来源

未配置 API 地址时，Wiki 与 Raw 页面使用 `lib/mock/research-fixtures.ts`。配置 `NEXT_PUBLIC_API_BASE_URL` 或 `INKDESK_API_BASE_URL` 后，页面读取 Python 后端。
