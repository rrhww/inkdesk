# 网页前端说明

前端是 Inkdesk 唯一的用户界面：以主题知识看板为主入口，附带可搜索、可缩放的图谱视图、知识健康面板、任务收件箱和只读 Harness Run 检查器。

## 路由

- `/`：重定向到 `/app/wiki`。
- `/app`：重定向到 `/app/wiki`。
- `/app/wiki`：主题知识看板（项目知识主题列表与搜索）。
- `/app/wiki/[id]`：主题简报（当前理解、关键决策、来源与相关资料）。
- `/app/wiki/graph`：知识图谱画布和 Markdown 阅读器。
- `/app/tasks`：任务收件箱（创建任务、上下文装配、状态流转）。
- `/app/health`：知识健康信号列表与处置（acknowledge / resolve / dismiss）。
- `/app/runs/[runId]`：只读 Harness Run 检查器（阶段、证据、五维评分、Findings 与报告）。

旧 Ask、Raw、Ingest、Compile、Skills 与 Dev Run 页面已经移除，未匹配路由渲染紧凑的「这个页面当前不存在」状态。

## 数据与交互

- 知识看板通过同源 `/api/knowledge/*` 读取主题与简报，订阅 `/api/knowledge/stream`（事件 `knowledge.updated`）做版本失效刷新。
- 任务收件箱通过 `/api/tasks` 读写任务，订阅 `/api/tasks/stream`（事件 `tasks.updated`）实时刷新。
- 图谱页通过同源 `/api/graph` 读取完整快照，并订阅 `/api/graph/stream`；`ALL / VAULT / REPO` 控制数据来源，`GLOBAL / TASK / MACRO` 控制图谱细节。
- Dagre 负责确定性布局；模块分组和语义缩放降低大图噪声；`@xyflow/react` 提供画布渲染。
- `Ctrl/Cmd+K` 聚焦搜索，节点点击打开 Markdown、代码高亮和 Mermaid 阅读器。

## 本地运行

```powershell
npm install
npm run dev
```

默认后端地址是 `http://localhost:8080`（Next 代理 `/api`）。可在 `.env.local` 中设置 `INKDESK_API_BASE_URL` 或 `NEXT_PUBLIC_API_BASE_URL`。

## 验证

```powershell
npm test
npm run typecheck
npm run lint
npm run build
npm run e2e
```

真实后端全链路验证需要本地服务已启动，可执行 `npm run e2e:fullstack`。
