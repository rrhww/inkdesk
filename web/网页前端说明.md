# 网页前端说明

前端是 Inkdesk 唯一的用户界面：一个全屏、可搜索和可缩放的研发知识图谱。

## 路由

- `/`：重定向到 `/app/wiki`。
- `/app`：重定向到 `/app/wiki`。
- `/app/wiki`：知识图谱画布和 Markdown 阅读器。

旧 Ask、Raw、Ingest、Compile、Health、Skills 与 Dev Run 页面已经移除。

## 数据与交互

- 页面通过同源 `/api/graph` 读取完整快照，并订阅 `/api/graph/stream`。
- `ALL / VAULT / REPO` 控制数据来源，`GLOBAL / TASK / MACRO` 控制图谱细节。
- Dagre 负责确定性布局；模块分组和语义缩放降低大图噪声。
- `Ctrl/Cmd+K` 聚焦搜索，节点点击打开 Markdown、代码高亮和 Mermaid 阅读器。

## 本地运行

```powershell
npm install
npm run dev
```

默认后端地址是 `http://localhost:8080`。可在 `.env.local` 中设置 `INKDESK_API_BASE_URL` 或 `NEXT_PUBLIC_API_BASE_URL`。

## 验证
